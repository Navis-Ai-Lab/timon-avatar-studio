# Changelog

## 0.1.0 — first public release

- Avatars page: prompt, presets (including Timon-style meerkats), seed, per-account gallery with hover details (prompt, seed, age)
- Set any image as an agent's picture in one click
- "Generate an avatar" entry in every agent's menu
- Settings pane: CPU thread count, editable presets
- Model download from the page (pinned commit) or manual install for offline servers
- English and French
- Generation queue (one at a time, at most 4 waiting), model unloaded after 10 idle minutes
- Migrates the shared gallery of pre-release builds into per-account galleries
